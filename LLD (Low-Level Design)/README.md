# LLD (Low-Level Design)

Low-Level Design is about how you structure code *inside* a system: the classes, their responsibilities, and how they talk to each other. Good LLD makes code easy to extend, test and maintain — and it's a standard round in software engineering interviews.

You'll learn:
- **Object-oriented programming** – classes, inheritance, polymorphism, abstraction  
- **SOLID principles** – guidelines for clean, flexible code  
- **Design patterns** – proven solutions like Singleton, Factory, Strategy and Observer  
- **UML & class diagrams** – sketching a design before you code it  
- **Designing real systems** – parking lot, library management, elevator, and more
