# Web Development

Web Development isn't just building websites or designing in Figma. It teaches you how most applications work and reach production — even in AI, edge devices and embedded systems. Concepts like **scaling, caching, load balancing and serverless architectures** carry over to almost every tech domain.

We'll keep it approachable and fun. There are plenty of great resources out there — pick the one that clicks with you, and lean on official documentation.

### Suggested path
1. **HTML & CSS** – page structure, Flexbox, Grid, responsive design  
2. **JavaScript** – async/await, Fetch API, storage, cookies and tokens  
3. **A frontend framework** – React is recommended (Next.js later), plus TailwindCSS  
4. **Backend** – Node.js + Express, REST APIs, CRUD, middleware  
5. **Databases** – MongoDB or PostgreSQL  
6. **Auth & security** – JWT/OAuth2, password hashing, HTTPS  
7. **Git & GitHub** – branching, pull requests, forking  
8. **Going further** – TypeScript, Docker, CI/CD, testing, WebSockets

## Problem Statements

The full briefs, requirements and acceptance criteria are in [web pses.md](./web%20pses.md). Each PS builds on the one before it, so do them in order.

| PS | Project | What you'll build | Tech |
| -- | ------- | ----------------- | ---- |
| 1 | **Online Course Registration Form** | An accessible sign-up form with semantic structure, labelled fields and built-in browser validation | HTML only |
| 2 | **Responsive Product Showcase Page** | A store landing page with a sticky navbar, hero section and product grid that adapts from mobile to desktop | HTML + CSS |
| 3 | **Task Manager with Local Storage** | A to-do app with add, edit, delete, filters and a live counter, which remembers tasks after the browser closes | HTML, CSS, vanilla JS |
| 4 | **Weather Dashboard** | A live weather app using a public API, with a 5-day forecast, °C/°F toggle, geolocation, recent searches and proper loading/error states | JS + `fetch`/`async-await` |

Every PS also has a **bonus** task if you want to push further.
