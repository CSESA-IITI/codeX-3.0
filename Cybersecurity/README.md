# Cybersecurity

A curated collection of Capture The Flag (CTF) platforms, learning resources and tools to build your cybersecurity skills.

CTFs are the best way in: each challenge hides a "flag" behind a security puzzle — cryptography, web exploits, reverse engineering and more. Start with the beginner platforms, then use the resource lists and tools as you go deeper.

---

## Resources

### Beginner-friendly platforms
- [picoCTF](https://picoctf.org/) – the most beginner-friendly CTF, with a primer to get started.  
- [CTF101](https://ctf101.org/) – an introductory guide to CTF concepts and methods.  
- [pwn.college Dojos](https://pwn.college/dojos) – binary exploitation and security fundamentals.  
- [CTFlearn](https://ctflearn.com/challenge/1/browse) – practice challenges across many categories.  
- [Google CTF Beginner's Quest](https://capturetheflag.withgoogle.com/beginners-quest) – web security and CTF basics.

### Learning resources
- [Awesome CTF Resources](https://github.com/devploit/awesome-ctf-resources) – a huge list of CTF resources, write-ups and tools.  
- [Paul Veillard's Cybersecurity CTF Repo](https://github.com/paulveillard/cybersecurity-ctf) – CTF challenges with solutions.  
- [CSIRT-MU Edu Resources](https://github.com/CSIRT-MU/edu-resources) – educational security material.  
- [CTF Resources for Beginners (Medium)](https://medium.com/technology-hits/capture-the-flag-ctf-resources-for-beginners-9394ee2ea07a) – an overview of where to start.

### Tools
- [CyberChef](https://gchq.github.io/CyberChef/) – the "cyber Swiss army knife" for encoding, decoding and hashing.  
- [RapidTables](https://www.rapidtables.com/) – quick calculators and converters.  
- [DogBolt](https://dogbolt.com/) – decompiler explorer for analysing compiled binaries.
