## Resources for the problem statement

These references support the [Suspicious Login Activity Analyzer](02_problem_statement.md). The Python documentation links are useful if you choose Python; the project can also be built in another language.

| Resource | How it helps |
| --- | --- |
| [Python tutorial](https://docs.python.org/3/tutorial/) | Review functions, loops, dictionaries, file handling, and exceptions. |
| [Python CSV module](https://docs.python.org/3/library/csv.html) | Read log rows by column name using `csv.DictReader`. |
| [Python datetime module](https://docs.python.org/3/library/datetime.html) | Parse timestamps, order events, and calculate rolling time windows. |
| [Python ipaddress module](https://docs.python.org/3/library/ipaddress.html) | Validate IPv4 and IPv6 addresses. |
| [Python collections module](https://docs.python.org/3/library/collections.html) | Group records and maintain recent events with tools such as `defaultdict` and `deque`. |
| [Python argparse module](https://docs.python.org/3/library/argparse.html) | Accept a file path, thresholds, and time-window settings from the command line. |
| [GitHub: About READMEs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) | Write clear project documentation that helps someone understand and run your work. |
