# Game Development

Explore game development through two practical tasks. Choose a language or engine that suits the project.

## Problem Statements

[Open the GameDev problem statements](./GameDev%20PS.md):

- **Terminal Wordle:** Build a word-guessing game with validation and feedback, including correct handling of repeated letters.
- **Themed Game:** Choose a three-level platformer or an endless arcade game and combine two themes as gameplay mechanics.
