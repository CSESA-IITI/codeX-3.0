# Game Dev Resources

A starting point for learning game engines and libraries. Pick one that suits you. Every option below is free to start with.

> Not sure which to choose? **Pygame** or **GameMaker** are the easiest for beginners, **Godot** is a great all-rounder for 2D, and **Unity** has the largest community and tutorial library.

---

## Game Engines

### Unity (C#)
Most popular engine, with a huge community. Good for 2D and 3D.
* [Unity Manual (official docs)](https://docs.unity3d.com/Manual/index.html)
* [Unity Scripting API](https://docs.unity3d.com/ScriptReference/)
* [Unity Learn (free official tutorials and courses)](https://learn.unity.com/)
* [Download Unity Hub](https://unity.com/download)

### Unreal Engine (C++ / Blueprints)
Best known for high-end 3D graphics. Blueprints let you build logic visually without code.
* [Unreal Engine Documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine)
* [Epic Developer Community Learning](https://dev.epicgames.com/community/unreal-engine/learning)
* [Download Unreal Engine](https://www.unrealengine.com/download)

### Godot (GDScript / C#)
Free, open source and lightweight. Very beginner friendly, especially for 2D.
* [Godot Documentation](https://docs.godotengine.org/en/stable/)
* [Getting Started: Your first 2D game](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html)
* [GDQuest (free tutorials)](https://www.gdquest.com/)
* [Download Godot](https://godotengine.org/download)

### GameMaker (GML)
Designed for 2D games, with drag-and-drop options for complete beginners.
* [GameMaker Manual](https://manual.gamemaker.io/)
* [GameMaker Tutorials and Learning Hub](https://gamemaker.io/en/tutorials)
* [Download GameMaker](https://gamemaker.io/en/download)

## Libraries and Frameworks

### Pygame (Python)
Simple 2D game library. A good first step if you already know Python.
* [Pygame Documentation](https://www.pygame.org/docs/)
* [Pygame Official Tutorials](https://www.pygame.org/wiki/tutorials)
* [Real Python: PyGame Primer](https://realpython.com/pygame-a-primer/)

### Phaser (JavaScript / TypeScript)
2D framework for making browser games.
* [Phaser Documentation](https://docs.phaser.io/)
* [Phaser Tutorials and Examples](https://phaser.io/learn)

### LÖVE / Love2D (Lua)
Lightweight 2D framework with a clean, simple API.
* [Love2D Wiki (official docs)](https://love2d.org/wiki/Main_Page)
* [Love2D Getting Started](https://love2d.org/wiki/Getting_Started)

### Raylib (C and many other languages)
Simple library for learning game programming. Has bindings for Python, C#, Java and more.
* [Raylib Website](https://www.raylib.com/)
* [Raylib Cheatsheet](https://www.raylib.com/cheatsheet/cheatsheet.html)
* [Raylib Examples](https://www.raylib.com/examples.html)
