# Learning Resources

Start with the basic concepts, then use the resources relevant to your chosen project. Completing an entire quantum computing course is not necessary before beginning.

## Quantum computing basics

**[IBM Quantum Learning: Superposition](https://quantum.cloud.ibm.com/learning/en/modules/quantum-mechanics/superposition-with-qiskit)** introduces qubit states, the Hadamard gate, and measurement. For PS1, use the concepts without copying SDK implementations.

**[IBM Quantum Learning: Learning modules](https://quantum.cloud.ibm.com/learning/en/modules)** provides introductions to quantum information and applications. Use it to look up unfamiliar concepts such as interference and entanglement.

## PS1: Circuit simulation and hidden-string recovery

**[IBM Quantum Learning: Quantum query algorithms](https://quantum.cloud.ibm.com/learning/en/courses/fundamentals-of-quantum-algorithms/quantum-query-algorithms/deutsch-jozsa-algorithm)** discusses the Bernstein–Vazirani hidden-string problem and its relationship to the Deutsch–Jozsa circuit. Focus on oracle access, interference, and what one query means.

**[Python numeric types](https://docs.python.org/3/library/stdtypes.html#numeric-types-int-float-complex)**, **[mathematical functions](https://docs.python.org/3/library/math.html)**, and **[random sampling](https://docs.python.org/3/library/random.html)** support amplitude storage, normalization, and measurement sampling. Pseudorandom sampling is suitable for these educational simulations; it is not quantum randomness.

**[NumPy beginner's guide](https://numpy.org/doc/stable/user/absolute_beginners.html)** is optional support for array operations. Implement the quantum operations yourself.

## PS2: Quantum communication

**[IBM Quantum Learning: Quantum key distribution](https://quantum.cloud.ibm.com/learning/en/modules/computer-science/quantum-key-distribution)** introduces basis choices and the detection of eavesdropping. Use it to understand the protocol before building the application workflow.

**[IBM Quantum Documentation: Install Qiskit](https://quantum.cloud.ibm.com/docs/en/guides/install-qiskit)** provides local installation guidance. Record the versions used in your README. Local simulation does not require proceeding to hardware-account setup.

**[Qiskit API reference](https://quantum.cloud.ibm.com/docs/en/api/qiskit)** documents circuit operations and quantum-state utilities. Consult the documentation matching your installed version for preparation and measurement.

## GitHub documentation

**[GitHub: About READMEs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)** explains how a README introduces a repository and helps others run a project. Include real commands and outputs from your implementation.
