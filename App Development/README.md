# App Development

App Development is about building applications that run on mobile devices and putting ideas directly into users' hands. It combines **design, functionality and performance** to make apps that solve real problems while staying easy to use.

Along the way you'll learn about:
- **Mobile ecosystems** – Android, iOS and cross-platform frameworks  
- **UI/UX design** for small screens  
- **Offline-first** principles  
- **APIs, databases and backend integration**  
- **Security and deployment** for real-world use  

Pick **one** stack below to start — Kotlin for native Android, or Flutter / React Native to ship on both Android and iOS from a single codebase.
