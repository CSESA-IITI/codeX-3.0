# Habit Tracker – PS1

**Difficulty:** Beginner

## Problem Statement

Building a routine is easier when progress is visible. Design a simple mobile app that helps users keep track of everyday habits without requiring an account or internet connection.

## Objectives

- Build a beginner-friendly app with a clear, intuitive interface.
- Practice basic navigation, forms, lists, and local persistence.
- Help users record daily progress with minimal effort.

## Features

- Add, edit, and delete habits (for example, reading or exercising).
- Mark a habit as completed for the current day.
- Display today's habits and their completion status.
- Show a simple streak or count of completed days for each habit.
- Save data locally so it remains after the app is closed.
- Provide an easy way to view past completion records.

## Tech Stack (Example)

- **Frontend:** Kotlin / Java (Android Studio), Flutter (Dart), or React Native
- **Storage:** SharedPreferences / DataStore, SQLite / Room, or equivalent local storage

## Notes

- No authentication, cloud backend, or external API is required.
- A clean, working app matters more than animations or elaborate design.
- Streaks are optional if the basic daily tracking flow is complete.
